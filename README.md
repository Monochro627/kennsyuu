# Monochro 新人研修アプリ

研修生 → ルームアドバイザー卒業までを支える、社内専用のWebアプリです（Google Apps Script）。
会社のGoogleアカウントでログインして使い、データは会社のドライブのスプレッドシートに保存されます。

要件と決定事項は [docs/requirements.md](docs/requirements.md) にまとめています。

## 第1弾でできること

| タブ | 内容 |
|---|---|
| 🎓 卒業フロー | 「黒から白へ」のステージ（8段階の階段）、ポイント・連続日数・今週の記録、バッジ12種、次にやること、卒業条件9項目と研修フローのチェック。フェーズ制覇・ステージアップ・卒業時はお祝い演出 |
| 👥 みんな | 今週のMVPと、進捗・ポイント・今週の記録で並べ替えられるランキング |
| 🎬 eラーニング | 旧サイトの動画111本（★①〜⑥の46本が必須）。動画の下で気づき・質問を入力すると視聴済みになる（Googleフォームの代わり） |
| 📘 マニュアル | 旧サイトのマニュアル26件。Googleドキュメントを編集元にして、アプリでは目次・画像・動画プレイヤー付きのウェブマニュアルとして表示。PDF保存ボタンあり |
| 🎙 ロープレ | ロープレ記録（話し手・聞き手・内容・FB）と録音ファイルの保存 |
| ⚙ 管理 | メンバー追加（研修生なら進捗シートを自動作成）、データ・フォルダへのリンク |

第2弾（AI文字起こし・要約・チャット）は未着手です。

## 初期設定（管理者が1回だけ）

所要時間は15分ほどです。**会社のGoogleアカウント（info@monochro-inc.com など）** で行ってください。

### 1. Apps Script プロジェクトを作る
1. https://script.google.com を開き「新しいプロジェクト」を作る。名前は「新人研修アプリ」など
2. 左の「サービス ＋」から **Drive API** を追加する（バージョン v3、ID は `Drive` のまま）
3. 左の「ファイル ＋」で次のファイルを作り、このリポジトリの `gas/` の中身をそれぞれ貼り付ける

| エディタで作るファイル | 貼り付ける中身 |
|---|---|
| スクリプト `Code`（最初からある「コード.gs」を書き換え） | `gas/Code.js` |
| スクリプト `Setup` | `gas/Setup.js` |
| スクリプト `SiteImport` | `gas/SiteImport.js` |
| スクリプト `Manual` | `gas/Manual.js` |
| HTML `index` | `gas/index.html` |

4. `Setup` の先頭の `ADMIN_NAME` が自分の名前になっているか確認する

### 2. setup を実行する
1. **旧Googleサイトの公開範囲が「ウェブ上で一般公開」になっていることを確認する**（取り込みのため。終わったら社内のみに戻す）
2. エディタ上部の関数選択で `setup` を選び「実行」→ 権限の確認画面で許可する
3. 2〜5分ほどで終わり、ドライブに「新人研修アプリ ※社外秘」フォルダができます
   - 研修アプリデータ ※社外秘（スプレッドシート）
   - 研修マニュアル（社内に閲覧共有）
   - ロープレ録音（社内に閲覧共有）
4. もし「実行時間の上限」で止まった場合は、`reimportSite` を実行すると続きから取り込みます
5. 終わったら **旧Googleサイトの公開範囲を社内のみに戻す**

### 3. Webアプリとして公開する
1. 右上の「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
2. 「次のユーザーとして実行」：**自分**、「アクセスできるユーザー」：**Monochro（組織内）の全員**
3. 「デプロイ」を押して表示されたURLを、研修生・教育担当に共有する

### 4. メンバーを登録する
アプリの「⚙ 管理」タブからメンバー（名前・会社メール・役割）を追加します。
**メンバー表にいない人はアプリを開けません。** 研修生を追加すると、その人の進捗シートが自動で作られます。

## やる気の仕組み

- **ステージ**：進捗率でBLACK → ONYX → CHARCOAL → GRAPHITE → SLATE → SILVER → PEARL → WHITE（ルームアドバイザー）と上がる
- **ポイント**：タスク10pt、卒業条件50pt、eラーニング動画5pt、ロープレ（話し手）20pt
- **連続日数**：チェック・動画の記録・ロープレのどれかをした日が続いた日数
- 計算は `gas/Code.js` の `stats_`、ステージとバッジは `gas/index.html` の `STAGES` と `BADGES` で変えられます

## 日々の運用

- **動画・マニュアルの追加や修正**：データのスプレッドシートの「資料マスター」に行を足す・直す
- **卒業条件・研修タスクの変更**：「卒業条件」「タスクマスター」を直す（すでにいる研修生の進捗シートには自動では反映されません）
- **マニュアル本文の更新**：「研修マニュアル」フォルダのGoogleドキュメントを直接編集（アプリの表示は次に開いたときに自動で更新）
- **コードを更新したとき**：エディタに貼り直して「デプロイ」→「デプロイを管理」→ 編集 → バージョン「新バージョン」

## 開発者向け：テスト

`test/` に Node で動く確認用スクリプトがあります。Apps Script のサービスはフェイク（`test/fake_gas.js`）に置き換えています。

```bash
node test/server.test.js                                   # サーバー側（Code.js / Setup.js / Manual.js）
node test/manual.test.js [ドキュメントのHTML書き出し]        # マニュアル表示用の整形
node test/site_import.test.js <保存したサイトHTML> <出力先>  # 旧サイト取り込み
NODE_PATH=$(npm root -g) node test/ui.test.js <rows.json> <スクショ出力先> [ドキュメントのHTML書き出し]  # 画面（Playwright）
```

サイト取り込みと画面のテストは、旧サイトのHTMLを保存したもの（社外秘のためリポジトリには含めない）を使います。
