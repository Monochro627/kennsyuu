# Monochro 新人研修アプリ

研修生 → ルームアドバイザー卒業までを支える、社内専用のWebアプリです（Google Apps Script）。
会社のGoogleアカウントでログインして使い、データは会社のドライブのスプレッドシートに保存されます。

要件と決定事項は [docs/requirements.md](docs/requirements.md) にまとめています。

## 第1弾でできること

| タブ | 内容 |
|---|---|
| 🎓 卒業フロー | 「黒から白へ」のステージ（8段階の階段）、ポイント・連続日数・今週の記録、次にやること、**ルームアドバイザー卒業要件11個のバッジ**（一番上は「あり方」、次が「実務スキル」）（押すと詳細が開き、達成にできる。eラーニング・ロープレ試験の進み具合も表示）、セットアップタスクのチェック。ステージアップ・卒業時はお祝い演出 |
| 👥 みんな | 今週のMVPと、進捗・ポイント・今週の記録で並べ替えられるランキング |
| 🎬 eラーニング | 旧サイトの動画111本（★①〜⑥の46本が必須）。動画の下で気づき・質問を入力すると視聴済みになる（Googleフォームの代わり） |
| 📘 マニュアル | 旧サイトのマニュアル26件。Googleドキュメントを編集元にして、アプリでは目次・画像・動画プレイヤー付きのウェブマニュアルとして表示。PDF保存ボタンあり |
| 🎙 ロープレ | **ロープレ試験（【試験①】〜⑦）**：「試験を実施」で日時入りの評価シートが評価者全員に届き、スマホで採点（1〜10、一部20点満点）・根拠・合否・FBを入力。全員合格で合格、結果は評価者ごとの点数表で見られ、ロープレ記録にも自動で残る。ほかに通常のロープレ記録と録音ファイルの保存 |
| ⚙ 管理 | メンバー追加（研修生なら進捗シートを自動作成）、データ・フォルダへのリンク |

第2弾（AI文字起こし・要約・チャット）は未着手です。

## 初期設定（管理者が1回だけ）

所要時間は15分ほどです。**会社のGoogleアカウント（info@monochro-inc.com など）** で行ってください。

### 1. Apps Script プロジェクトを作る
1. https://script.google.com を開き「新しいプロジェクト」を作る。名前は「新人研修アプリ」など
2. 左の「サービス ＋」から **Drive API** を追加する（バージョン v3、ID は `Drive` のまま）
3. 左の「ファイル ＋」で次のファイルを作り、このリポジトリの `gas/` の中身をそれぞれ貼り付ける

| エディタで作るファイル | 貼り付ける中身 |
|---|---|
| スクリプト `Code`（最初からある「コード.gs」を書き換え） | `gas/Code.js` |
| スクリプト `Setup` | `gas/Setup.js` |
| スクリプト `SiteImport` | `gas/SiteImport.js` |
| スクリプト `Manual` | `gas/Manual.js` |
| スクリプト `Exam` | `gas/Exam.js` |
| スクリプト `Flow` | `gas/Flow.js` |
| スクリプト `Editor` | `gas/Editor.js` |
| スクリプト `Arikata` | `gas/Arikata.js` |
| スクリプト `Advanced` | `gas/Advanced.js` |
| HTML `index` | `gas/index.html` |

4. `Setup` の先頭の `ADMIN_NAME` が自分の名前になっているか確認する

### 2. setup を実行する
1. **旧Googleサイトの公開範囲が「ウェブ上で一般公開」になっていることを確認する**（取り込みのため。終わったら社内のみに戻す）
2. エディタ上部の関数選択で `setup` を選び「実行」→ 権限の確認画面で許可する
3. 2〜5分ほどで終わり、ドライブに「新人研修アプリ ※社外秘」フォルダができます
   - 研修アプリデータ ※社外秘（スプレッドシート）
   - 研修マニュアル（社内に閲覧共有）
   - ロープレ録音（社内に閲覧共有）
4. もし「実行時間の上限」で止まった場合は、`reimportSite` を実行すると続きから取り込みます
5. 終わったら **旧Googleサイトの公開範囲を社内のみに戻す**

### 3. Webアプリとして公開する
1. 右上の「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
2. 「次のユーザーとして実行」：**自分**、「アクセスできるユーザー」：**Monochro（組織内）の全員**
3. 「デプロイ」を押して表示されたURLを、研修生・教育担当に共有する

### 4. メンバーを登録する
アプリの「⚙ 管理」タブからメンバー（名前・会社メール・役割）を追加します。
**メンバー表にいない人はアプリを開けません。** 研修生を追加すると、その人の進捗シートが自動で作られます。

## 研修フローの「扱い」

タスクマスターの「扱い」列で、タスクの見せ方が決まります（`gas/Flow.js`）。

| 扱い | 見え方 |
|---|---|
| チェック（空欄も同じ） | 研修フローのチェックボックス。進捗率に入る |
| メモ | チェック＋実施日。全部終わらせなくてよく、進捗率に入らない（依頼コンサルなど） |
| G01〜G09 | その卒業要件を開いたときの「この要件でやること」（例：G04 事務作業ワーク） |
| ロープレ一覧 | ロープレのページの「ロープレの種類」に並ぶだけ |
| 目安：〇〇 | 卒業フローの「入社からの目安」の表に、〇〇の列として並ぶだけ |
| 応用：〇〇 | 卒業フローの一番下の「応用編（主任以降）」に〇〇編として並ぶ。カテゴリごとに開くチェック。進捗率に入らない |

## 卒業要件「あり方」「実務スキル」

知識（試験）ややり方（ロープレ）とは別に、身だしなみ・LINEのアイコン・遅刻をしない・報連相など「Monochroの一員としての姿勢」を見る要件です（`gas/Arikata.js`）。
- 卒業要件の一番上にバッジがあり、開くとカテゴリごとに「〇〇ができている状態」のチェック項目が並ぶ
- 本人が自分でチェックし、教育担当が日々の様子を見て、すべてできていれば「達成」にする
- 「実務スキル」は設備の理解・初期費用の説明・概算見積書・重要事項説明書・期待値調整。教育担当が実際の説明や書類を見て確認する
- どちらも中身はタスクマスターの「扱い」をその要件のIDにした行。アプリを開いたときに1回だけ自動で足され、あとは編集モードで自由に直せる（外しても勝手に戻らない）

## 応用編（主任以降）

新人研修のあと、売買などをさばけるようになりたい人の枠です（`gas/Advanced.js`）。卒業要件ではないので進捗率には入りません。
- 賃貸編：原状回復（ガイドライン・通常損耗・経過年数・特約・精算書）、敷金と契約のルール（敷引き・定期借家・連帯保証の極度額など）、資格（敷金診断士の合格）の14項目
- 売買編：マンション・戸建て・売却・媒介・契約・宅建業法・住宅ローン（短期プライムレート・店頭金利・5年ルール・125%ルール・ローン電卓・銀行ごとの特徴など）・お金・税金の39項目（アプリを開いたときに1回だけ自動で足される）
- 編集モードで項目を直せるほか、「研修フローにまとまりを足す」で種類を「応用編」にすると、新しい枠（例：法人編）を作れる
- 今はメンバー表の役割が「研修生」の人だけにチェック表がある

## データの保存先と、項目の編集

- アプリのデータは「研修アプリデータ ※社外秘」だけに保存する。元の「モノクロトレーニングプログラム」（研修フロー）は setup で1回読んだだけで、アプリから書き換えることも、元を直してアプリが変わることもない
- ロープレ評価シート（【試験①】〜）だけは、元を直したあと `reimportExams` を実行すると取り込み直せる
- 管理者・教育担当は、卒業フローの「✎ 編集モード」で卒業要件とタスクを直せる：文言の修正、追加、外す（「（保留）」シートへ移す）、⋮⋮のドラッグか↑↓で並び替え、まとまりの名前の変更、置き場所（研修フロー・卒業要件の中身・入社からの目安・ロープレの種類）の変更、新しいまとまりの追加（`gas/Editor.js`）

## 管理タブでできること

- **メンバー追加／まとめて登録**：1行に「名前, メール, 役割」で複数人を一度に登録（役割を省くと教育担当）。ロープレ試験の実施画面からも、管理者は評価者をその場で登録できる
- **研修フローの整理**：「扱い」が入っていない古い形のタスクマスターを、今の形（セットアップ研修・依頼コンサル・事務作業ワーク・ロープレの種類・入社からの目安）に並べ替える。IDは変わらないのでチェックは消えない
- **マニュアルを作り直す**：旧Googleサイトから変換し直す（ページ内の目次がくっついてスマホで読みにくかったのを直したもの）。旧サイトを一時的に一般公開にしてから押す

## ほかのアプリから特定のタブを開く

URLの末尾に `?tab=タブ名` を付けると、そのタブから始まります（例：`…/exec?tab=roleplay` でロープレ）。
タブ名は `home`（卒業フロー）・`all`（みんな）・`elearning`・`manuals`・`roleplay`・`admin`（管理者・教育担当のみ）。
見込みボード（Monochro CRM）の左メニューの「新人研修」は、このURLへのリンクです。

## やる気の仕組み

- **ステージ**：進捗率でBLACK → ONYX → CHARCOAL → GRAPHITE → SLATE → SILVER → PEARL → WHITE（ルームアドバイザー）と上がる
- **ポイント**：タスク10pt、卒業条件50pt、eラーニング動画5pt、ロープレ（話し手）20pt、ロープレ試験の合格30pt
- **連続日数**：チェック・動画の記録・ロープレのどれかをした日が続いた日数
- 計算は `gas/Code.js` の `stats_`、ステージとバッジは `gas/index.html` の `STAGES` と `BADGES` で変えられます

## 自動デプロイ（GitHub → GAS）

`gas/` のコードが GitHub に入ると、GitHub Actions（`.github/workflows/deploy-gas.yml`）がテストを流してから
clasp で Apps Script に送り、今のデプロイを新バージョンに差し替えます（URL は変わりません）。
エディタへの貼り直しとデプロイの操作は要りません。

### 最初に1回だけやること
1. https://script.google.com/home/usersettings で「Google Apps Script API」をオンにする（スマホでも可）
2. clasp でログインして認証情報を作る（会社のGoogleアカウントで）
   - PC：Node.js を入れてから、ターミナルで `npx @google/clasp@2.4.2 login` → ブラウザで許可 → ホームフォルダの `.clasprc.json` ができる
   - PCがない場合：GitHub のこのリポジトリで「Code」→「Codespaces」から開き、ターミナルで `npx @google/clasp@2.4.2 login --no-localhost` → 表示されたURLを開いて許可し、出てきたコードを貼る → `cat ~/.clasprc.json`
3. GitHub のこのリポジトリの Settings → Secrets and variables → Actions → New repository secret
   - Name：`CLASPRC_JSON`
   - Secret：`.clasprc.json` の中身をまるごと
4. Actions タブの「GASへ自動デプロイ」→「Run workflow」で1回動かして確かめる

初回の送信で、エディタのファイル名は `Code`・`Setup`・`index` などに整理されます（前の `gas/Code.js` などは置き換わります）。
`CLASPRC_JSON` は Apps Script を書き換えられる鍵です。人に見せず、要らなくなったら Google アカウントの「サードパーティのアクセス」から clasp を外してください。
シークレットがまだないあいだは、Actions はテストだけ流してデプロイを飛ばします。

## 日々の運用

- **動画・マニュアルの追加や修正**：データのスプレッドシートの「資料マスター」に行を足す・直す
- **卒業条件・研修タスクの変更**：「卒業条件」「タスクマスター」を直す（すでにいる研修生の進捗シートには自動では反映されません）
- **ロープレ試験の評価項目を変えたとき**：元の「ロープレ フィードバック＆評価ポイント＆設定事例」の【試験①】〜シートを直してから、エディタで `reimportExams` を実行（「20点」と書いた項目は20点満点、「※」で始まる項目は点数なしの参考項目になる。【試験⑧】のようにシートを足せば試験も増やせる）
- **マニュアル本文の更新**：「研修マニュアル」フォルダのGoogleドキュメントを直接編集（アプリの表示は次に開いたときに自動で更新）
- **コードを更新したとき**：自動デプロイを設定していれば何もしなくてよい。設定前は、エディタに貼り直して「デプロイ」→「デプロイを管理」→ 編集 → バージョン「新バージョン」

## マニュアルの編集で反映されるもの

Googleドキュメントで編集した内容のうち、アプリのマニュアル表示に反映されるのは次のとおりです。

| 反映される | 反映されない（アプリの見た目に統一） |
|---|---|
| 見出し（「見出し1〜3」スタイル。見出し1・2は番号付きの章、3は小見出しになり、目次にも出る）／太字・斜体・下線／文字色／マーカー（背景色）／画像／箇条書き・番号付きリスト／表／リンク／YouTubeのリンク（「▶ 動画」と書いた行は再生プレイヤーになる） | フォントの種類・文字サイズ・行間・中央寄せなどの配置・画像の回り込み |

## 開発者向け：テスト

`test/` に Node で動く確認用スクリプトがあります。Apps Script のサービスはフェイク（`test/fake_gas.js`）に置き換えています。

```bash
node test/server.test.js                                   # サーバー側（Code.js / Setup.js / Manual.js）
node test/manual.test.js [ドキュメントのHTML書き出し]        # マニュアル表示用の整形
node test/site_import.test.js <保存したサイトHTML> <出力先>  # 旧サイト取り込み
NODE_PATH=$(npm root -g) node test/ui.test.js <rows.json> <スクショ出力先> [ドキュメントのHTML書き出し]  # 画面（Playwright）
```

サイト取り込みと画面のテストは、旧サイトのHTMLを保存したもの（社外秘のためリポジトリには含めない）を使います。
