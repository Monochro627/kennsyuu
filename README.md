# 新人営業研修アプリ

研修生 → ルームアドバイザー 卒業までをサポートする、スマホでも使える軽量Webアプリです。
サーバー・ビルド不要（HTML/CSS/JSのみ）で、GitHub Pages などにそのまま置けます。

## 機能

| | 機能 | 内容 |
|---|---|---|
| ① | 卒業フロー | ステップごとのタスクをチェック → 進捗バー・「次のステップ」を表示（進捗は各端末のブラウザに保存） |
| ② | 資料・動画 | YouTube / Googleドライブはアプリ内で表示、Googleサイトは別タブ。ステップ別絞り込み・検索あり |
| ③ | AIチャット | NotebookLM の共有ノートブックを開くボタン＋質問例（タップでコピーして開く） |

## 内容の編集方法

**`js/data.js` だけ編集すればOK** です。

- `steps` … 卒業までのステップとタスク（現在はサンプル）
- `materials` … 資料・動画のリンク
- `notebookLmUrl` … NotebookLM の共有リンク

### 資料を追加する時のポイント
- Googleドライブのファイルは「リンクを知っている全員」または「社内全員」に共有してください。
- YouTube は「限定公開」がおすすめです。

## 重さについて（Googleサイトとの関係）
資料一覧ではファイル本体を読み込まず、**タップした時だけ** 表示するので、資料が増えてもアプリは重くなりません。
Googleサイトは埋め込み表示ができない仕様のため、リンクとして別タブで開きます（資料の置き場所はGoogleサイト／ドライブのままでOK）。

## NotebookLM について
NotebookLM はGoogleの仕様上、他のアプリ内への埋め込み（iframe）や公開チャットAPIが提供されていないため、
共有リンクで別タブ（スマホではアプリ）を開く形にしています。

## 公開方法（GitHub Pages）
リポジトリの Settings → Pages → Branch を選択して保存すると、`https://<ユーザー名>.github.io/kennsyuu/` で公開されます。
※ 社外秘資料のリンクが含まれる場合は、公開範囲にご注意ください（リンク先のGoogle側の共有設定で閲覧制限がかかります）。
