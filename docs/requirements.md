# 新人営業研修アプリ 要件（グリルミーで決定）

最終更新：2026-10-24

## 1. 全体方針

| 項目 | 決定内容 |
|---|---|
| 土台 | **Google Apps Script（GAS）Webアプリ**。会社のGoogleアカウントでログインし、社外の人は開けない |
| データ置き場 | **アプリ専用のスプレッドシートを新しく作る**（既存のスプレッドは参考資料としてそのまま残す） |
| 進捗の持ち方 | アプリで管理し、保存先として研修生ごとのシートを使う（タスクマスターをコピーして自動で作る） |
| 権限 | 「メンバー」シートで役割を決める（研修生／教育担当／管理者）。表に名前がない人はアプリを開けない |
| リリース | 第1弾：進捗＋資料（APIキー不要）→ 第2弾：AI関連 |

## 2. データ構成（研修アプリデータ）

```
研修アプリデータ（新規スプレッド）
├ メンバー         名前｜メール｜役割｜入社日
├ タスクマスター   フェーズ｜カテゴリ｜タスク｜ポイント   ←（新）研修フローフォーマットから移す
├ 資料マスター     タイトル｜種別｜URL｜フェーズ｜チャットに読ませる(☑)
├ <研修生名>       タスクマスターのコピー＋完了チェック｜チェックした人｜日時
├ ロープレ記録     日付｜所要時間｜話し手｜聞き手｜内容｜課題｜録音リンク｜文字起こし｜要約｜FB
└ eラーニング記録  日時｜研修生｜動画｜気づき｜質問｜AI仮回答
```

## 3. 機能

### ① 卒業フロー（研修生 → ルームアドバイザー）
- フェーズ：入社前セットアップ → 依頼コンサル → ひたすらロープレ → 物件用語・現地 → 事務処理 → 2週間後の効果測定（インスタ開始）→ 1ヶ月間 → 卒業検定（1〜3ヶ月目）→ ルームアドバイザー → 主任要件
- **チェックは研修生・教育担当のどちらでも付けられる**（誰がいつ付けたかを記録）
- **全員の進捗一覧は研修生も含めて全員が見られる**
- 管理者はアプリから研修生を追加でき、追加するとその人の進捗シートが自動で作られる

### ② 資料・動画
- **Googleサイト（Training Program／e-ラーニング）は引退し、アプリに一本化する**
- 資料と動画は「資料マスター」シートで管理し、フェーズごとに表示する
- 一覧では本体を読み込まず、開いた時だけ読み込む（重くならない）
- eラーニング：動画の下で気づき・質問を入力する → 視聴済みが付く（Googleフォームは不要になる）
  - 第2弾：質問にはClaudeが先に仮の回答を返す

### ③ ロープレ記録・録音
- アプリで録音 → 音声はDriveの「ロープレ録音」フォルダに保存 → ロープレ記録に1行追加
- 第2弾：**Geminiで文字起こし**（話し手と聞き手を区別）→ **Claudeで要約と、評価ポイントに沿ったフィードバック**
  - Claudeは音声を直接読めないため、文字起こしはGeminiに任せる

### ④ AIチャット（第2弾）
- **アプリ内にClaudeでチャットを作る**（NotebookLMは使わない）
- 答えの根拠は、**資料マスターで「チャットに読ませる」に☑を付けた資料だけ**（管理者が選ぶ）
  - 営業マニュアルは古いので、更新するまで☑を付けない運用にする

## 4. 未確定・準備してほしいもの

- 移行対象の在籍中の研修生（小田さん・宮川さんなど、どなたを移すか）
- 第2弾用：Gemini APIキーとClaude APIキー（GASのスクリプトプロパティに保存する）
